# Metronom

A simple browser-based metronome with:

- Adjustable click speed (BPM)
- Switchable time signatures (for example 4/4, 3/4, 2/2)
- Adjustable counted note values (half, quarter, eighth, sixteenth, etc.)
- Visual beat + measure counter
- Configurable accent on a selected beat

## Run

Open `index.html` in your browser.
